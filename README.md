# Digital Safe System

## Project Overview
This project is a **Digital Safe System** designed to provide secure access through a two-step authentication process:

1. **Numeric Code Verification:** Validating the entered numerical code.
2. **Password Verification:** Validating the entered password.

Both authentication steps must be successfully completed to grant access to the safe.

## Simulation Environment
The project is designed and simulated using **Proteus**.

## Hardware Components
The system consists of the following components:

- **RAM:** Handles input, output, and result data.
- **ROM:** Stores the numerical code and password and instructions of 8086.
- **Multiplexer:** Selects and routes input signals.
- **Four Decoders:** Used for decoding operations.
- **8086 Microprocessor:** Performs comparison and verification of both numerical codes and passwords.
